# ADR-005：模型画像与测评来源

日期：2026-11-14。状态：已采用。

模型标识、Provider、模型版本和角色分离。能力未知用缺失值表示，不在硬要求下当作零分或满足要求。人工数值标记为 `user_override`；历史无效画像保留原始内容并隔离禁用，用户可以修复。模型的工具调用和结构化输出支持分别记录确认状态及来源；请求同时受模型画像与适配器能力约束。

真实网关观测与注入传输的 Mock 观测分别持久化和汇总，不将 Mock 延迟、得分或费用称作实际供应商表现。固定版本任务集执行模型请求并使用确定性比较器评分，保存样本、输出、运行模式和来源；少量 smoke 题仅验证协议，不足以作为模型能力证据或团队选择的研究结论。未来研究应另设独立评估集、防止测试集污染，明确样本量、置信区间及消融实验。

当前真实凭据未用于本机验证；模型能力未知、费用资料缺失时维持 unknown。Provider 凭据不写入模型画像或基准结果。接入真实 Worker 和外部副作用前仍须满足 ADR-004 的治理条件。
